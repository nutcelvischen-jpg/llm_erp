# ERP 資料庫說明（供 Text-to-SQL 使用）

公司：台中精密零件公司（軸承、齒輪、墊片、扣件、客製件）。資料庫為 PostgreSQL。
**只能查詢下列四個 View**，View 與欄位名稱都是中文，SQL 中一律用雙引號包住，例如 `"v_銷售明細"."銷售金額"`。
「今天」一律用 `CURRENT_DATE`，不要寫死日期。金額單位為新台幣元。

## 1. v_銷售明細（一列 = 一張訂單的一個品項；不含已取消訂單）
| 欄位 | 型別 | 說明 |
|---|---|---|
| 訂單編號 | text | 例 SO20261012-003 |
| 訂單日期 | date | 接單日，**計算營收／業績一律用這個日期** |
| 出貨日期 | date | 待出貨訂單為 NULL |
| 訂單狀態 | text | 待出貨／已出貨／已結案 |
| 客戶代號、客戶名稱 | text | 例 C008、鴻遠機械 |
| 客戶區域 | text | 北部／中部／南部／海外 |
| 負責業務 | text | 陳怡君、林建宏、黃雅婷、張志豪、李佩珊、王俊傑 |
| 料號、品名 | text | 例 BRG-6205-2RS、深溝球軸承 6205-2RS |
| 產品類別 | text | 軸承／齒輪／墊片／扣件／客製件 |
| 數量 | int | |
| 單價、單位成本 | numeric | |
| 銷售金額 | numeric | 數量 × 單價（未稅） |
| 毛利 | numeric | 數量 × (單價 − 單位成本) |

**陷阱**
- 毛利率 = `SUM("毛利") / SUM("銷售金額")`，**不要**對每列毛利率取平均。
- 營收 = `SUM("銷售金額")`，用「訂單日期」篩選期間；「已出貨金額」才用出貨日期。
- 同期比較（去年同期）：`EXTRACT(YEAR FROM "訂單日期")` 搭配 `"訂單日期" <= CURRENT_DATE - INTERVAL '1 year'` 截到同一天，不要拿整年對比未完成的今年。
- 本月 = `"訂單日期" >= DATE_TRUNC('month', CURRENT_DATE)`；本季、今年同理用 `DATE_TRUNC('quarter' / 'year', ...)`。
- 季度用 `EXTRACT(QUARTER FROM "訂單日期")`；Q3 = 7–9 月。

## 2. v_應收帳款（一列 = 一張發票）
| 欄位 | 型別 | 說明 |
|---|---|---|
| 發票號碼 | text | |
| 客戶代號、客戶名稱、負責業務 | text | |
| 發票日期、到期日 | date | |
| 發票金額 | numeric | 含稅 |
| 已收金額 | numeric | |
| 未收金額 | numeric | 發票金額 − 已收金額 |
| 逾期天數 | int | 未收且已過到期日才 > 0，否則為 0 |

**定義**
- 逾期應收 = `"未收金額" > 0 AND "逾期天數" > 0`；「逾期超過 60 天」= `"逾期天數" > 60 AND "未收金額" > 0`。
- 客戶欠款總額 = `SUM("未收金額")` 依客戶分組。
- 帳齡分段：1–30、31–60、61 天以上，用 `CASE WHEN "逾期天數" BETWEEN ...`。

## 3. v_庫存狀況（一列 = 一個啟用中的料號）
| 欄位 | 型別 | 說明 |
|---|---|---|
| 料號、品名、產品類別、單位 | text | |
| 現有庫存 | int | |
| 安全庫存 | int | |
| 標準成本 | numeric | |
| 庫存金額 | numeric | 現有庫存 × 標準成本 |
| 最後異動日 | date | 最近一次出貨或進貨日 |
| 未異動天數 | int | 今天 − 最後異動日 |
| 供應商、供應商交期天數 | text / int | |
| 待出貨數量 | numeric | 狀態為「待出貨」的訂單所需數量（即未來約 3 週要出的貨） |
| 在途數量 | numeric | 狀態為「待交貨」的採購單數量 |

**定義**
- 呆滯料號 = `"未異動天數" >= 180 AND "現有庫存" > 0`；壓住的資金 = `SUM("庫存金額")`。
- 缺料 = `"現有庫存" + "在途數量" < "待出貨數量" OR "現有庫存" < "安全庫存"`。
- 缺口 = `"待出貨數量" - "現有庫存" - "在途數量"`；**建議採購量** = `缺口 + "安全庫存"`（缺口小於 0 時以 0 計）。
- 預計何時會缺料 / 來不來得及：比較「供應商交期天數」與出貨急迫度。

## 4. v_採購明細（一列 = 一張採購單的一個品項）
| 欄位 | 型別 | 說明 |
|---|---|---|
| 採購單號 | text | |
| 採購日期、預計到貨日、實際到貨日 | date | 未到貨者實際到貨日為 NULL |
| 採購狀態 | text | 待交貨／已收貨／取消 |
| 供應商 | text | |
| 料號、品名 | text | |
| 數量、單位成本、採購金額 | | 採購金額 = 數量 × 單位成本 |

**定義**
- 交期達成率 = 已收貨中 `"實際到貨日" <= "預計到貨日"` 的筆數 ÷ 已收貨筆數。
- 採購單含「取消」狀態，統計採購金額時請排除 `"採購狀態" = '取消'`。

## 一般規則
1. 只輸出一個 SELECT；結果取前幾名時務必 `ORDER BY ... LIMIT n`。
2. 金額用 `ROUND(..., 0)`，毛利率用 `ROUND(100.0 * ..., 1)` 並以 % 表示。
3. 問題沒指定期間時，預設用「今年到目前為止」。
4. 問題問「誰、哪些」→ 回傳名稱欄位 + 數值欄位；不要只回傳代號。
5. 沒有資料可以回答的問題（例如員工薪資、競爭對手），不要硬寫 SQL。

## 範例
問：今年營收最高的 3 個客戶
```sql
SELECT "客戶名稱", ROUND(SUM("銷售金額"), 0) AS "營收"
FROM "v_銷售明細"
WHERE "訂單日期" >= DATE_TRUNC('year', CURRENT_DATE)
GROUP BY "客戶名稱" ORDER BY "營收" DESC LIMIT 3;
```
問：目前逾期超過 60 天的應收有哪些客戶？
```sql
SELECT "客戶名稱", COUNT(*) AS "張數", ROUND(SUM("未收金額"), 0) AS "未收金額"
FROM "v_應收帳款"
WHERE "未收金額" > 0 AND "逾期天數" > 60
GROUP BY "客戶名稱" ORDER BY "未收金額" DESC;
```
問：哪些料號超過 180 天沒動？壓了多少錢？
```sql
SELECT "料號", "品名", "現有庫存", ROUND("庫存金額", 0) AS "庫存金額", "未異動天數"
FROM "v_庫存狀況"
WHERE "未異動天數" >= 180 AND "現有庫存" > 0
ORDER BY "庫存金額" DESC LIMIT 50;
```
